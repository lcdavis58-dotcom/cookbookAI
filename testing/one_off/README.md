# testing/one_off/

A scratch folder for quick, throwaway checks and their output: a script that tries a parser on a few real lines, a saved trace or frequency report, a copy of the recipe index.

Everything here except this README is git-ignored. These files are usually built from real cookbook text, and the published repository must never contain other people's books.

Reusable diagnostics that don't contain book text live in `tools/diagnostics/` instead (see its README).
